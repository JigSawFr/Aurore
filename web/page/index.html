Aurore's demo, in your browser

The real library, compiled with Emscripten: the same code as on a Switch, drawn with WebGL 2. Click the screen, then:

  • ←↑→↓ move the focus
  • Enter Ⓐ
  • Esc Ⓑ
  • X Y L R the buttons of the same name
  • F12 the inspector

A click is a touch; the pad (on a touch screen, shown at once) has the controller's buttons.
